# Copilot 指令文件

本项目要求所有生成与修改的代码注释遵循 `C:\Users\majim\Desktop\rules.md` 中的规则。请在后续自动生成代码时严格按以下指令执行：

- 流水代码注释：将简洁中文注释放在代码行尾，尽量在同一列对齐。
- 块注释：在代码块的 `{` 后添加简要中文说明，注释与 `{` 同行。
- 复杂逻辑：在逻辑前使用多行 `//` 注释，段落清晰，中文描述规则和背景。
- 函数注释：不使用 Doxygen；在函数定义的 `{` 后添加一句中文功能说明。
- 大括号：左右大括号必须在同一列上对称。

附加要求：
- 注释保持简洁，避免冗长；与代码保持一致性。
- 使用中文注释，不混用英文，除非为专有名词或API名称。
- 对硬件相关调用如 `HAL_`、`osThread*` 保持行尾简短说明。
- 新增文件与修改文件均需遵循以上规范。
