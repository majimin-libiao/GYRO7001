# XV7001BB Gyro Sensor – Hardware and Driver Reference

## 1. Power Supply
- Main power supply (VDDM): 2.7V to 3.6V
- I/O logic supply (VDDI): 1.65V to 3.6V (should match MCU IO voltage)
- Recommended decoupling capacitors:  
  - VDDM: 1uF + 1u~10uF  
  - VDDI: 1uF + 1u~10uF  
  - VDDL: (Regulator output) 1uF

## 2. Pinout and SPI Wiring

| Pin No. | Pin Name      | Direction        | Description                                          | Connection           |
| ------- | ------------- | --------------- | ---------------------------------------------------- | ---------------------|
| 1       | MOSI/SDA      | Input/Output    | SPI MOSI / I2C SDA                                   | SPI MOSI from MCU    |
| 2       | SS            | Input           | Chip select, active low (pull low during SPI access) | Any MCU GPIO (e.g., PB12) |
| 3       | VDDL          | Output          | Internal regulator output, connect 1uF cap           | ---                  |
| 4       | Reserved1     | Input           | Must be connected to GND                             | GND                  |
| 5       | GND           | Power           | Ground                                               | GND                  |
| 6       | VDDM          | Power           | Main supply voltage                                  | 2.7-3.6V             |
| 7       | Reserved2     | Output          | Logic "L", do not connect                            | NC                   |
| 8       | VDDI          | Power           | Digital interface supply                             | 1.65-3.6V            |
| 9       | MISO/SA0      | Output/Input    | SPI MISO / I2C Address select                        | SPI MISO to MCU      |
| 10      | SCLK/SCL      | Input           | SPI clock / I2C SCL                                  | SPI SCK from MCU     |

**Note:** For 4-wire SPI, use pins 1, 2, 9, 10. Reserved1 (#4) must be tied to GND.

## 3. SPI Electrical and Timing Characteristics

- SPI Modes Supported: 4-wire (default), 3-wire
- Typical operating mode: 4-wire SPI, Mode 0 (CPOL=0, CPHA=0)
- Data width: 8 bits per word
- MSB first
- Max SCLK frequency:
  - 10 MHz if VDDI = 2.4V ~ 3.6V
  - 5 MHz if VDDI = 1.65V ~ 2.4V
- MOSI setup/hold: ≥10ns
- MISO access time: ≤100ns
- Chip Select (SS) is active low, must remain low for the whole SPI transaction
- You must wait ≥1ms after power-up before first SPI communication

## 4. Recommended STM32 SPI Settings

- Master mode
- 8-bit data size
- CPOL = 0, CPHA = 0 (SPI Mode 0)
- NSS: software managed (use MCU GPIO for CS, e.g., PB12)
- SPI clock ≤10MHz
- MSB first

## 5. Power-on and SPI Init Sequence

1. Power up VDDM and VDDI.
2. Wait at least 1ms (tIF) before SPI communication.
3. Pull CS (SS) low, begin SPI transfer.
4. Address: 8 bits (MSB = 1 for read, 0 for write), followed by register address (A4:A0).
5. For write: after address, send 8-bit data; for read: receive 8-bit data on second byte.
6. Keep CS low during transaction, pull CS high to finish.

## 6. Typical SPI Connection Example

MCU (e.g. STM32) ↔ XV7001BB:
- MOSI  <-> Pin 1 (MOSI/SDA)
- MISO  <-> Pin 9 (MISO/SA0)
- SCLK  <-> Pin 10 (SCLK/SCL)
- CS    <-> Pin 2 (SS) (e.g., STM32 PB12)
- GND   <-> Pin 5 (GND), Pin 4 (Reserved1)
- VDDM  <-> Pin 6
- VDDI  <-> Pin 8

Don't connect Reserved2 (#7), VDDL (#3) only needs decoupling capacitor (1uF to GND).

## 7. SPI Register Protocol Overview

- First byte: 8 bits
  - MSB=1: read, MSB=0: write
  - Bits A[6:5]: slave address (usually '00' for single device)
  - Bits A[4:0]: register address
- Second byte: data (for write: send; for read: receive)
- Relevant registers:
  - 0x08: Temperature Data
  - 0x0a: Angular Rate Data
  - 0x0b: Data output/control
  - 0x1f: Serial interface settings (e.g., 4-wire/3-wire SPI, I2C enable)

## 8. Example Power and Decoupling Circuit

- Each VDDx to GND: 1uF in parallel with 1u~10uF tantalum/ceramic
- VDDL: 1uF only, not used for powering other devices
- Schematic: see figure 7.1 in datasheet

## 9. Environmental and Safety Notes

- Avoid ESD, overvoltage, or reverse voltage
- Reserved registers must not be written
- Allow 0.01~100ms ramp-up of power supply at start
